## 💡 user 도움 요청

위 9개 후보 중 URL 미정인 것들을 채우려면:

**(A) user가 직접 URL 주기** (가장 빠름)
- 각 계정 들어가서 후킹 된 포스트/영상 URL 복붙해서 보내주기
- 계정당 2~4개 URL이면 OK
- "이 계정에서 제일 후킹 되는 스타일 알려줘" 식 간단 코멘트 환영

**(B) Claude가 WebSearch로 인덱스된 것 먼저 탐색** (제한적)
- WebSearch는 아주 최근 바이럴 콘텐츠 일부만 잡음
- user가 실제 앱에서 보는 콘텐츠의 질은 확실히 더 나음

**(C) instaloader 스크립트로 자동 수집** (세팅 필요)
- IG만 가능, TikTok/YT는 별도 도구 필요
- IG 세션 로그인 필요 (본인 계정 정보)

추천: **(A) + (B) 병행** — user가 편할 때 URL 몇 개 툭툭 던져주고,
나는 그 사이에 WebSearch로 보완.
