# Saju Thai — mini-site

A Korean Four-Pillars (사주팔자) calculator aimed at Thai readers, with English
toggle. Designed to be linked from an Instagram bio. The core computations
match the Korean **포스텔러 / 천을귀인 만세력** apps:

- Four pillars (년/월/일/시) with stems, branches, 지장간, 십성, 12운성
- Auspicious / inauspicious stars (천을귀인, 양인, 역마, 도화, 화개, 백호대살 …)
- Great-luck cycles (대운), yearly run (세운), monthly run (월운)
- True-solar-time correction per birth city (e.g. Bangkok ≈ −22 min vs KST)
- **Paid deep readings** at 79 / 129 / 199 THB via Stripe Payment Links,
  generated by Claude API

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r minisite/requirements.txt
# Paid readings need secrets (copy and fill in):
cp minisite/.streamlit/secrets.toml.example minisite/.streamlit/secrets.toml
streamlit run minisite/app.py
```

## Deploy to Streamlit Community Cloud (free)

1. Push the repo to GitHub.
2. [streamlit.io/cloud](https://streamlit.io/cloud) → *New app*.
3. Main file: `minisite/app.py`; branch: the feature branch.
4. **App settings → Secrets**: paste the keys from
   `.streamlit/secrets.toml.example` with real values.
5. The resulting URL (e.g. `https://duangsaju.streamlit.app`) goes in the
   Instagram bio.

## Paid-reading setup

The free chart always works — paid readings only show up once secrets are
configured. Steps:

### 1. Claude API key

1. Go to https://console.anthropic.com/settings/keys → create a key.
2. Set a monthly usage cap in the Anthropic console to bound cost.
3. Put it in Streamlit secrets as `ANTHROPIC_API_KEY`.

The app uses `claude-opus-4-7` with adaptive thinking + high effort. Cost
is roughly \$0.05–0.10 per reading — well under the 79–199 THB price point.

### 2. Stripe — account + payment links

1. Create a Stripe account at https://dashboard.stripe.com/register.
   Thailand is supported; verification takes a business day.
2. Get the **secret key** from
   https://dashboard.stripe.com/apikeys → put in secrets as
   `STRIPE_SECRET_KEY` (start with `sk_test_...` while testing).
3. Create **three Payment Links** at
   https://dashboard.stripe.com/payment-links, one per tier:

   | Tier   | Amount (THB) | Redirect URL (After-payment) |
   |--------|--------------|------------------------------|
   | Core   | 79           | `https://<your-app>.streamlit.app/?paid=1&tier=core&session_id={CHECKOUT_SESSION_ID}` |
   | Yearly | 129          | `https://<your-app>.streamlit.app/?paid=1&tier=yearly&session_id={CHECKOUT_SESSION_ID}` |
   | Full   | 199          | `https://<your-app>.streamlit.app/?paid=1&tier=full&session_id={CHECKOUT_SESSION_ID}` |

   For each link: **Payment confirmation → Don't show confirmation, redirect
   to a URL**. The `{CHECKOUT_SESSION_ID}` template is replaced by Stripe at
   checkout time — leave it literal.

4. Copy each Payment Link URL into secrets as `STRIPE_PAYMENT_LINK_CORE` /
   `_YEARLY` / `_FULL`.

### 3. Flow

1. User generates the free chart.
2. Picks a tier → `st.link_button` opens the Stripe Payment Link with a
   base64-encoded `client_reference_id` containing their birth profile.
3. Stripe processes the payment and redirects back to
   `?paid=1&tier=...&session_id=...`.
4. App verifies with `stripe.checkout.Session.retrieve()`, decodes the
   birth profile, computes the chart, and streams the Claude reading.

### 4. Economics cheatsheet

- Stripe fee in Thailand: ~3.65% + ~10 THB fixed = ~13 THB on a 199 THB sale.
- Claude API: ~\$0.05–0.10 per reading ≈ 2–4 THB.
- Net per 199 THB sale: ~180 THB (≈ \$5) — ~90% margin.

## Notes on calculation

- Uses `lunar_python` for the base calendar + ganzhi resolution, then
  overrides hidden stems with the full classical 초기/중기/정기 table Korean
  apps use.
- True-solar-time correction:
  `(city_longitude − standard_meridian) × 4 min`. A second shift moves the
  clock to the KST (135° E) reference so ganzhi match Korean manseryeok.
- Daewoon direction: yang-year male or yin-year female → forward; otherwise
  backward. Starting age comes from `lunar_python`'s Yun API.
- Reading-tier prompts are cached via Anthropic prompt caching (marker on
  the system block); repeat readings hit ~90% discount on the system input.
